# CodeStar

## Descrição

Aplicação gamificada voltada ao aprendizado de lógica de programação por meio da criação e execução de ritmos musicais.

## Tecnologias

* JavaScript
* React
* Vite
* Node.js e npm
* Web Audio API (prevista para a reprodução sonora)
* Git e GitHub

## Execução local

```bash
npm install
npm run dev
```

## Status

Ambiente inicial de desenvolvimento e estrutura-base do projeto.
